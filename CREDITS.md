## FluidX3D licence obligations (read LICENSE.md in the clone before submission)
1. Non-commercial; **no military use**; **no training AI models on its source**.
2. We run an *altered* version (see above). Rule 5: if results or data generated by it are published, the altered source must be
   published too - `tools/fluidx3d/setup.cpp.template` + `patch_defines()` in this repository **are** that altered source; keep them public
   together with any published Tier 2 result and do not publish fields without them.
3. Rule 6: scientific write-ups must cite the FluidX3D articles listed under "References" in its README.
4. Never claim FluidX3D output as the team's own kernels: every table and plot names its wind tier.
